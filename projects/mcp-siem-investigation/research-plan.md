# Research Plan

## Project Goal

Build an MCP-enabled AI security investigation system and systematically evaluate when it works, when it fails, and which controls improve its reliability.

## Guiding Research Question

How reliably can an LLM-based assistant use MCP-exposed SIEM capabilities to investigate security events, and how does that reliability change under adversarial conditions and after security controls are introduced?

## Experimental Model

Baseline
→ Adversarial Conditions
→ Security Controls
→ Re-test
→ Compare Outcomes
